# 2026 加樂團契服事表 Web 版

本專案依照 `2026-10-12-加樂服事表.xlsx` 的原始 17 欄合併儲存格結構、顏色規範與全部 14 週名單完整還原製作，目前為純前端靜態網頁（支援本機暫存與直接列印），並已預留未來串接後台資料庫與教會行事曆的介面。

## 檔案結構

```text
jiale-roster-web/
├── index.html               # 主頁面（含桌機完整17欄表格 + 手機週次卡片視圖 + 季度行事曆彈窗）
├── css/
│   └── style.css            # 響應式樣式表（桌機表格 / 手機卡片 RWD / A4 橫式列印樣式）
├── js/
│   ├── default-data.js      # 由原始 Excel 轉換之 2026 Q4（10-12月）14週預設資料
│   ├── api-service.js       # 資料存取抽象層（目前走 localStorage，已預留 REST API 串接接口）
│   └── app.js               # 雙向即時編輯、同工搜尋高亮、週次篩選、JSON 匯入/匯出邏輯
├── data/
│   └── default-roster.json  # 純 JSON 格式資料備份（未來可直接匯入資料庫）
└── README.md                # 使用與後台串接說明文件
```

## 核心功能說明

1. **格式 100% 還原與行內直接修改（Inline Editing）**：
   - 固定欄位（日期、崗位標題、招待地點標籤、車輛編號、量血壓標籤等）鎖定防誤觸。
   - 所有**組長名稱、講員、信息主題、敬拜主領/配唱、詩歌曲目、樂手、音控、攝影、招待、愛宴、接送司機、點名、交誼廳、體操、值班**皆可直接點擊文字進行修改。
   - 修改後自動暫存於瀏覽器的 `localStorage`，重新整理頁面不會遺失；亦可透過右上角「匯出備份」下載 `.json` 檔案分享給其他同工匯入。

2. **手機版閱讀體驗優化（週次任務卡片模式）**：
   - 17 欄寬表格在手機螢幕上需要不斷左右滑動且字體過小。當螢幕寬度小於 `900px`（手機/直式平板）時，系統會自動切換為**「週次任務卡片視圖」**：
     - 頂部提供**橫向滑動週次膠囊列**（10月1日 ~ 12月31日），一鍵跳轉至指定日期。
     - 每週聚會依服事性質分為 6 個清晰區塊（信息講員、敬拜詩歌、影音體操值班、招待點名、愛宴接送、交誼廳血壓），單手上下滑動即可瀏覽與點擊修改，且修改內容與全表模式即時雙向同步。
     - 若在手機上仍想看完整 Excel 寬表，可隨時點擊頂部切換鈕切回「全表模式」。

3. **未來動態後台串接預留（`js/api-service.js`）**：
   - `RosterApiService` 已封裝 `getRoster()`、`saveRoster()`、`patchCell()` 與 `generateQuarterWeeksWithCalendar(year, quarter, targetWeekday)`。
   - 未來建立後端資料庫後，只需將 `USE_REMOTE_API` 設為 `true` 並填入 API 網址即可無痛升級；介面上的「📅 季度/放假設定」已可先體驗季度週次試算與手動標記放假/休會週次。
